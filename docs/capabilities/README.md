# Capability Specs

These documents define the active capability contracts for the MVP foundation.

The governing entry point above them is:

- `docs/GOVERNANCE_MODEL.md`

Each capability spec should answer:

- purpose
- ownership
- core entities
- exposed APIs
- event responsibilities
- dependencies
- MVP scope
- current gaps

These specs are subordinate to:

- `docs/GOVERNANCE_MODEL.md`
- `docs/FOUNDATIONAL_ARCHITECTURE.md`
- `docs/CAPABILITY_MATRIX_MVP.md`
- `docs/IMPLEMENTATION_ALIGNMENT.md`
- `docs/adr/`
