# ADR 0003: Anchor The MVP On The Commercial Operations Wedge

## Status

Accepted

## Context

The product vision spans many capability areas, but implementation needs a single measurable operating slice.

## Decision

The MVP is anchored on this wedge:

`Lead -> Customer -> Order -> Inventory -> Sale`

Modules and features are prioritized by how directly they strengthen this flow.

## Consequences

Benefits:

- creates a clear prioritization rule
- enables end-to-end validation
- reduces spread across speculative surfaces

Tradeoffs:

- some visible product areas will remain partial longer
